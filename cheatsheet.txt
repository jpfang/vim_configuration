║                                                      ║
║  ===== Nvim - Code Navigation =====                  ║
║  w         Go to definition                          ║
║  q         Jump back                                 ║
║  sw        Find all references                       ║
║  gy        Go to type definition                     ║
║  gi        Go to implementation                      ║
║  \k        Hover docs / definition info              ║
║                                                      ║
║  ===== Nvim - Diagnostics =====                      ║
║  [d        Previous diagnostic                       ║
║  ]d        Next diagnostic                           ║
║                                                      ║
║  ===== Nvim - Edit =====                             ║
║  \rn       Rename symbol                             ║
║  \fm       Format code                               ║
║  Tab       Completion: next candidate                ║
║  Shift-Tab Completion: previous candidate            ║
║  Enter     Confirm completion                        ║
║                                                      ║
║  ===== Nvim - Telescope =====                        ║
║  \ff       Find file (opens in new tab)              ║
║  \fg       Live grep (opens in new tab)              ║
║  \fb       Search buffers                            ║
║  \fs       Document symbols (outline)                ║
║                                                      ║
║  ===== Nvim - Window / Tab =====                     ║
║  Tab v     Vertical split                            ║
║  Tab s     Horizontal split                          ║
║  Tab-Arrow Switch pane                               ║
║  Tab m     Maximize current pane                     ║
║  Tab `     Restore equal size                        ║
║  tn        Next tab                                  ║
║  tp        Previous tab                              ║
║                                                      ║
║  ===== Nvim - Other =====                            ║
║  F2        Show this cheatsheet                      ║
║  F3        Toggle NvimTree                           ║
║  F4        Toggle Tagbar                             ║
║  `         Save (:w)                                 ║
║  \`        Close window (:q)                         ║
║                                                      ║
║  ===== Tmux (prefix: Ctrl-l) =====                   ║
║  Ctrl-l c       New window                           ║
║  Ctrl-l "       Horizontal split pane                ║
║  Ctrl-l %       Vertical split pane                  ║
║  Ctrl-l n       Next window                          ║
║  Ctrl-l p       Previous window                      ║
║  Ctrl-l d       Detach session                       ║
║  Ctrl-l x       Close pane                           ║
║  Ctrl-l r       Reload tmux.conf                     ║
║  Ctrl-l m       Mouse ON                             ║
║  Ctrl-l M       Mouse OFF                            ║
║  Alt-Left       Previous window                      ║
║  Alt-Right      Next window                          ║
║  Shift-Arrow    Switch pane                          ║
║  Alt-Up         Enter copy mode                      ║
║  Alt-Down       Choose session                       ║
║                                                      ║
